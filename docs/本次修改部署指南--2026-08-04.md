## 一、服务器前置检查

### 1.1 服务器数据库缺列（必须补）

以下列在**本地已存在**但**服务器未补**，部署前必须 ALTER：

```bash
# SSH 到服务器后执行

# ① pms_attribute 属性定义模型列
docker exec csmall-mysql mysql -uroot -p"$MYSQL_ROOT_PASSWORD" -e "
ALTER TABLE cs_mall_pms.pms_attribute
  ADD COLUMN description varchar(500) DEFAULT NULL COMMENT '属性简介' AFTER name,
  ADD COLUMN input_type int DEFAULT 0 COMMENT '输入类型' AFTER type,
  ADD COLUMN value_list text COMMENT '备选值列表 JSON' AFTER input_type,
  ADD COLUMN unit varchar(16) DEFAULT NULL COMMENT '计量单位' AFTER value_list,
  ADD COLUMN is_allow_customize int DEFAULT 0 COMMENT '是否允许自定义' AFTER sort;
"

# ② pms_sku_specification SKU规格新模型列
docker exec csmall-mysql mysql -uroot -p"$MYSQL_ROOT_PASSWORD" -e "
ALTER TABLE cs_mall_pms.pms_sku_specification
  ADD COLUMN attribute_name varchar(64) DEFAULT NULL COMMENT '属性名称' AFTER attribute_id,
  ADD COLUMN attribute_value varchar(64) DEFAULT NULL COMMENT '属性值' AFTER attribute_name,
  ADD COLUMN unit varchar(16) DEFAULT NULL COMMENT '计量单位' AFTER attribute_value,
  ADD COLUMN sort int DEFAULT 0 COMMENT '排序序号' AFTER unit,
  MODIFY COLUMN attribute_value_id bigint NULL COMMENT '旧模型属性值id（已废弃，可空）';
"

# ③ pms_attribute_template 模板扩展列
docker exec csmall-mysql mysql -uroot -p"$MYSQL_ROOT_PASSWORD" -e "
ALTER TABLE cs_mall_pms.pms_attribute_template
  ADD COLUMN pinyin varchar(64) DEFAULT NULL COMMENT '模板名称拼音' AFTER name,
  ADD COLUMN keywords varchar(255) DEFAULT NULL COMMENT '关键词列表' AFTER pinyin,
  ADD COLUMN sort int DEFAULT 0 COMMENT '自定义排序序号' AFTER keywords;
"

# ④ 4 张关联表补 gmt_modified
for db_tbl in cs_mall_pms.pms_brand_category cs_mall_pms.pms_category_attribute_template cs_mall_ams.ams_role_permission cs_mall_ams.ams_admin_role; do
  docker exec csmall-mysql mysql -uroot -p"$MYSQL_ROOT_PASSWORD" -e "ALTER TABLE $db_tbl ADD COLUMN gmt_modified datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '最后修改时间' AFTER gmt_create;" 2>&1 | grep -v "Duplicate\|exists"
done
```

### 1.2 验证补列结果

```bash
# 应看到 description/input_type/value_list/unit/is_allow_customize
docker exec csmall-mysql mysql -uroot -p"$MYSQL_ROOT_PASSWORD" -e "SHOW COLUMNS FROM cs_mall_pms.pms_attribute;" | grep -E "description|input_type|value_list|unit|allow_customize"

# 应看到 attribute_name/attribute_value/unit/sort
docker exec csmall-mysql mysql -uroot -p"$MYSQL_ROOT_PASSWORD" -e "SHOW COLUMNS FROM cs_mall_pms.pms_sku_specification;" | grep -E "attribute_name|attribute_value|unit|sort"

# 应看到 pinyin/keywords/sort
docker exec csmall-mysql mysql -uroot -p"$MYSQL_ROOT_PASSWORD" -e "SHOW COLUMNS FROM cs_mall_pms.pms_attribute_template;" | grep -E "pinyin|keywords"
```

## 二、需要重建的服务

| 服务 | 原因 | 注意 |
|------|------|------|
| **mall-product** | 改了大量 Controller/Mapper/Service/DTO | 核心服务，重启时 front/order/seckill/ai 短暂不可用 |
| **mall-order** | `updateOrderState` 权限 + 状态流转逻辑 | 独立重启不影响其他 |
| **mall-seckill** | `SeckillManageController` hasRole→isAuthenticated | |

### 2.1 打包后端 JAR

```bash
# 本地执行（在 D:\java\csmall 下）
./mvnw -pl mall-product/mall-product-webapi -am package -DskipTests -q
./mvnw -pl mall-order/mall-order-webapi -am package -DskipTests -q
./mvnw -pl mall-seckill/mall-seckill-webapi -am package -DskipTests -q
```

### 2.2 上传并替换 JAR

```bash
# 本地执行
scp mall-product/mall-product-webapi/target/mall-product-webapi-0.0.1-SNAPSHOT.jar ecs-user@8.156.77.197:/tmp/mall-product.jar
scp mall-order/mall-order-webapi/target/mall-order-webapi-0.0.1-SNAPSHOT.jar ecs-user@8.156.77.197:/tmp/mall-order.jar
scp mall-seckill/mall-seckill-webapi/target/mall-seckill-webapi-0.0.1-SNAPSHOT.jar ecs-user@8.156.77.197:/tmp/mall-seckill.jar

# 服务器执行
sudo mv /tmp/mall-product.jar /data/csmall/jars/mall-product.jar
sudo mv /tmp/mall-order.jar /data/csmall/jars/mall-order.jar
sudo mv /tmp/mall-seckill.jar /data/csmall/jars/mall-seckill.jar
```

### 2.3 重建容器

```bash
cd /data/csmall && docker compose up -d --build mall-product mall-order mall-seckill
```
