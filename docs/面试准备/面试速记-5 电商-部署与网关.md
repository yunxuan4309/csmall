## 前端代理速记（Vite vs Nginx）

```
本质相同：浏览器只看到代理地址(5173/80)同源，代理服务端转发
         到后端——服务端之间没有跨域
dev 用 Vite：要"快"——实时编译热更新 + 内置 proxy 一行配置
             解决跨域（nginx 做不了热更新）
生产用 Nginx：要"稳"——静态托管(gzip/缓存/高并发)+反向代理
             分发（Vite 是开发工具不适合生产）
类比：脚手架(Vite)方便改造，正式大楼(Nginx)才能住人
```

## Docker/K8s 速记（Q8）

```
Docker vs jar：环境一致(镜像带完整环境)/隔离/秒级部署/版本管理/资源限制
Compose vs K8s：单机编排 vs 多机集群；K8s 强在自愈/扩缩容/滚动更新，前提是多机
K8s 架构：控制平面=API Server+etcd(状态库,3/5副本,挂了全瘫)+Scheduler+Controller
          工作节点=kubelet+kube-proxy；etcd 最需维护
单机装 K8s：k3s(~500MB,推荐)/minikube(学习)/kubeadm(生产多机)
你的选择：单机 4C16G 不装(内存剩2G,价值用不上,Compose够)；学习时 k3s
容器=镜像只读层+可写层(详见 Docker容器原理详解 与 基础知识速记 19)
```

## Gateway 速记（Q9）

```
网关不止一个：Java=Gateway(Zuul1停更/Zuul2没人用/ShenYu多协议)
             Nginx系=Kong/APISIX  Go系=Traefik/Envoy/BFE
             云原生=Istio/Higress；选Gateway=SCA生态+Nacos lb://
大厂自研：入口层=LVS+Nginx/Tengine(阿里开源)
         应用网关层=自研或二次开发(阿里Higress/字节BFE开源/美团京东不公开)
         自研原因=规模压顶+协议定制+打通内部设施+团队摊成本
Netty vs WebFlux：Netty=底层引擎(NIO事件循环)；WebFlux=响应式
                 框架(Reactor Mono/Flux)；引擎≠框架，Tomcat也有响应式模式
SCG转发六步：入站Tomcat→路由匹配(Path命中)→过滤器链→lb://负载均衡
            (Nacos查实例轮询选)→NettyRouting Filter用WebClient
            (reactor-netty)转发→响应回Tomcat写回
            用WebClient不用RestTemplate=非阻塞+支持SSE
            核心=lb://服务名→(Nacos查实例轮询)→真实IP，路由静态地址动态
响应式性能：本质=少线程少切换；阻塞吞吐上限=线程数÷单请求耗时
            (200线程×200ms=1000req/s)；非阻塞等I/O不占线程在途请求不受限
            诚实点=非阻塞不加速单请求、低并发无感、业务阻塞全白搭
实测⭐：响应式✅(Reactive上下文+SentinelWebFluxFilter日志实证)
       但引擎=Tomcat不是Netty(日志"Tomcat started"+线程http-nio-10087)
路由：locator.enabled:false防全部暴露(23服务全公网可达)
     白名单机制：手写=白名单(没配的路径网关404到不了服务)
     lb://=Nacos查实例+LB转发，默认轮询可切random
     prod 10条/test 11条(多admin/**)
     pms直连原因⭐=product的dubbo应用名撞spring名→Nacos混入20880实例→
     lb://打到Dubbo端口；根治=改名mall-product-dubbo(TODO#6)
     Gateway转不了Dubbo(HTTP网关vs TCP RPC)
TraceId：网关生成塞X-Trace-Id头→下游读进MDC→日志[%X{traceId}]
         统一；只覆盖HTTP链路(定时任务/MQ/Dubbo线程[]空)
GlobalFilter=所有请求(大门保安)/GatewayFilter=绑定路由(楼层闸机)
诚实点：Gateway 无规则数据源+0规则=网关层流控空转
```

## 核心故障（挑 2-3 个讲）

- **ES red**：IK 分词器丢失（Docker 重建不持久）→ 重装 + 挂载持久化
- **Sentinel 失效**：Nacos 空配置覆盖本地规则 → Nacos 建规则
- **压测全"已购买"**：同用户重复 → 100 真实用户解决
- **SkyWalking Alpine 崩溃**：musl 不兼容 MD5 → 换 Debian 镜像（详见 10-问题解决 Q12）
- **BCrypt 误判纠错**：$2a 跨平台归因证伪 → 真因是哈希≠密码（详见 10-问题解决 Q11）
