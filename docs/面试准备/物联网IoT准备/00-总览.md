## 与电商项目的差异（面试必讲）

| 维度 | CoolShark 电商 | 智慧路灯 IoT |
|------|---------------|-------------|
| 核心 | 高并发 + 事务 | **设备安全 + 实时数据** |
| 通信 | HTTP + Dubbo | **MQTT** |
| 数据 | MySQL 关系型 | **TDengine 时序** |
| AI | DeepSeek RAG（电商导购） | **MaxKB RAG（维修诊断）** |
| 硬件 | 无 | **真实硬件（小熊派）** |
