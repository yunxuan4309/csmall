# 面试速记-1 开场与全局（面试前 5 分钟快速过）

> **所属**：面试速记版分册 1/7。完整深挖见 00-总览 对应维度文档。
> **场景**：进门自我介绍、被问"项目是什么/为什么/团队/重做改什么"等全局问题。

---

## 一、开场自我介绍（30 秒）

> "我是全栈开发者，做过两个完整项目：
> **CoolShark 微服务电商**（11 微服务，秒杀高并发 + AI 导购）和**智慧路灯 IoT**（EMQX + TDengine + 真实硬件）。
> 电商体现高并发后端能力，IoT 体现设备安全 + 实时数据 + AI 诊断，两个项目都独立完成并部署上线。"

---

## 二、两个项目对比（必讲差异化）

| | 电商 | IoT |
|---|------|-----|
| 核心 | 高并发 + 事务 | 设备安全 + 实时数据 |
| 通信 | HTTP + Dubbo | MQTT |
| 数据 | MySQL | TDengine 时序 |
| AI | DeepSeek 导购 | MaxKB 维修诊断 |
| 硬件 | 无 | 小熊派真实硬件 |

---

## 三、诚实边界（避免夸大）

- ❌ 不说"支撑 10 万 QPS"（没测）
- ❌ 不说"高可用集群"；如实说已做跨机双实例（#4 秒杀两实例）+ Redis 主从哨兵（#9）**验证机制**，但只有两台机器、机器宕机仍全挂
- ✅ 说"学习项目，架构和流程完整，数据测试级"
- ✅ 说"知道单点中间件是短板，生产要 HA"

---

## 四、通用问题应对

| 问题 | 应对 |
|------|------|
| 你为什么用这个技术 | 场景匹配 + 生态一致 + 踩过坑 |
| 遇到过什么难题 | 讲故障（ES red / Sentinel 失效 / MaxKB OOM）|
| 如果重做会改什么 | 中间件集群 / 监控告警 / 密钥随机化 |
| 团队多少人 | 独立完成，全栈 |
| 怎么排查问题 | 复现 → 分层 → 工具 → 根因 → 防复发 |
