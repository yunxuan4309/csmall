## 格式约定

```markdown
### Q1. 大问题（简答）
**追问1**：更深一层
**追问2**：边界情况/如果...
【简答】：2-3 句核心要点
【深挖】：追问的详细答案（基于真实项目）
```

## 使用建议

1. **先通读简答**，建立全局认知
2. **再攻追问**，每个追问都是真实面试可能问到的
3. **划重点**：标 🔴 的是一定要能答上来的核心
4. **诚实原则**：所有数字都是项目真实数据，面试时若被追问细节，
   用"具体可以查代码/文档确认"应对，不编造

## 面试核心逻辑（贯穿所有维度）

> **你的项目亮点**：微服务 + 高并发秒杀 + AI 导购 + 全链路可观测
> **面试官想验证**：① 是不是你做的（细节追问）② 懂不懂原理（为什么）③ 有没有踩坑经验（问题解决）
> **回答策略**：每讲一个技术，
> 都落到"解决了什么问题"+"有什么量化结果"+"踩过什么坑"
