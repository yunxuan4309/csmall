# 面试速记-6 IoT 项目与差异化（面试前 5 分钟快速过）

> **所属**：面试速记版分册 6/6。完整深挖见 物联网IoT准备/ 目录。
> **场景**：被问 IoT 项目或"两个项目对比"时。

---

## 设备鉴权（最大亮点）

```
EMQX 认证链：built_in(backend) → MySQL(设备凭证)
每设备独立凭证：username=deviceId, 密码=出厂编号+识别码
存储：BCrypt(密码) + AES-256-CBC(出厂编号，运维可查)
ACL：设备只能访问 streetlight/{deviceId}/#
TLS：ssl://8883 加密
```

## 数据管道

```
设备 → MQTT → EMQX → 规则引擎直写 TDengine（绕过后端）
后端只做业务（决策/告警/控制）
```

## AI 诊断（MaxKB）

```
三段式：本地正则 → AI 意图识别 → RAG 问答
自然语言调参：7 参数白名单，改真实策略
OOM 解决：内存限制 + 假 celery 替身
```

## 其他亮点

- 边缘计算：ConditionEvaluator 纯函数，断网自主决策
- 健康评分：0.30离线+0.25通信+0.25响应+0.20传感器，<60 告警
- 真实硬件：小熊派 BearPi，source 字段区分真实/模拟

## 两项目对比速记

| | 电商 | IoT |
|---|------|-----|
| 核心 | 高并发 + 事务 | 设备安全 + 实时数据 |
| 通信 | HTTP + Dubbo | MQTT |
| 数据 | MySQL | TDengine 时序 |
| AI | DeepSeek 导购 | MaxKB 维修诊断 |
| 硬件 | 无 | 小熊派真实硬件 |
| 一句话 | 后端高并发能力 | 设备安全 + 实时链路 |
