## 一、背景与机制

Nacos 2.5.2 默认**无认证**（无 token 读配置 200）。内网失陷后可无认证操作 + 注册假服务（服务伪装）。
**2.4+ 关键差异**：不再内置默认密码——首次开鉴权后需通过 API **初始化管理员密码**，之后客户端用 `nacos/<密码>` 登录换 token。

**认证参数**（compose nacos environment）：
| env | 用途 |
|---|---|
| NACOS_AUTH_ENABLE=true | 开鉴权 |
| NACOS_AUTH_TOKEN | JWT 签名密钥（Base64 ≥32 字节随机串）|
| NACOS_AUTH_IDENTITY_KEY/VALUE | 服务端间身份识别 |

**客户端连接点（全部要配账号，漏配=该服务起不来）**：
| 连接类型 | 涉及 | 配置字段 |
|---|---|---|
| Spring Cloud discovery | 11 服务 | `spring.cloud.nacos.discovery.username/password` |
| Dubbo registry | product/order/seckill/ums/ams/front/search/ai（8 个）| `dubbo.registry.username/password` |
| Sentinel datasource | seckill/order/sso/ai（4 个）| `spring.cloud.sentinel.datasource.{flow,degrade}.nacos.username/password` |
| Seata | **不连 Nacos**（file 模式）| 无需配 ✅ |

**凭据**（已生成，见本地密码备忘录，不入库）：
- NACOS_AUTH_TOKEN / NACOS_AUTH_IDENTITY_VALUE：compose → .env
- NACOS_PASSWORD：nacos 用户密码（初始化后客户端用它）

## 三、服务器执行（⚠️ 全量同步变更，同一窗口完成）

### Step 0: .env 加凭据（先备份）
```bash
cp /data/csmall/.env /data/csmall/.env.bak-20260908-nacos
# 追加(值=本地备忘录里的 3 个随机值)
cat >> /data/csmall/.env <<'EOF'
NACOS_AUTH_TOKEN=<值>
NACOS_AUTH_IDENTITY_VALUE=<值>
NACOS_PASSWORD=<值>
EOF
```

### Step 1: 同步 compose（AI 已传到 /tmp/docker-compose.yml）
```bash
sudo cp /data/csmall/docker-compose.yml /data/csmall/docker-compose.yml.bak2-20260908
sudo mv /tmp/docker-compose.yml /data/csmall/docker-compose.yml
sudo chown ecs-user:ecs-user /data/csmall/docker-compose.yml
# 确认 nacos 段含认证 env + 服务段含 NACOS_USERNAME
grep -A5 "container_name: csmall-nacos" /data/csmall/docker-compose.yml | grep -E "AUTH|IDENTITY"
```

### Step 2: 重建 nacos（先只动 nacos，初始化密码）
```bash
cd /data/csmall
docker compose up -d --build nacos
sleep 20
# 验证: 无 token 访问应 403
curl -s -o /dev/null -w "%{http_code}\n" "http://localhost:8848/nacos/v1/cs/configs?dataId=x&group=y"
# 预期 403
```

### Step 3: 初始化 nacos 管理员密码（2.4+ 无默认密码，必须执行）
```bash
# 密码用 .env 的 NACOS_PASSWORD
PASS=$(grep '^NACOS_PASSWORD=' /data/csmall/.env | cut -d= -f2-)
curl -s -X POST "http://localhost:8848/nacos/v1/auth/users/admin" -d "password=$PASS"
# 预期 {"username":"nacos","password":"..."} 成功
# 验证登录
curl -s -X POST "http://localhost:8848/nacos/v1/auth/login" -d "username=nacos&password=$PASS"
# 预期返回 accessToken
```

### Step 4: 重建全部 11 个微服务（同一窗口）
```bash
# 先 product(order/seckill 等依赖它先起), 再并行其余
cd /data/csmall
docker compose up -d --build mall-sso mall-product mall-order mall-seckill mall-ums mall-ams mall-front mall-search mall-ai mall-resource mall-gateway
# 或分批: 先 product, 观察注册成功后再起其余
```

## 四、回滚
| 场景 | 回滚 |
|---|---|
| 某服务起不来(漏配) | 查日志定位 401/403 → 补账号 → 重建该服务 |
| 大面积失败 | 还原 .env.bak + compose.bak2 → `docker compose up -d --build nacos` 先关认证 → 全量重启 |
