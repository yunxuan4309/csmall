## 第一段：秒杀压测（0:15–1:45）🔴 重点

**目标**: 展示高并发秒杀 + Sentinel 限流 + Redis 预扣 + MQ 削峰

### 操作步骤
1. 打开秒杀专区页（顶部导航"秒杀专区"）
2. 展示秒杀商品列表（有倒计时）
3. 切到 SSH 终端，执行压测脚本（100 并发）
4. 切到 Sentinel Dashboard（SSH 隧道 8090）看限流曲线
5. 切到 SkyWalking UI（SSH 隧道 8088）看调用链
6. 展示压测结果：成功 ~10 / 被限流 ~80

### 讲解话术
> **秒杀是电商最考验后端能力的功能**。我用压测脚本模拟 100 个用户同时抢购。看 Sentinel 控制台——QPS 一上来就被限流到 10，超过的请求直接返回"服务器忙"，保护了后端不被压垮。
>
> 秒杀链路有四个关键设计：**第一**，Redis 预扣库存，把库存判断放在缓存层；**第二**，RabbitMQ 异步落库，创建订单走消息队列削峰；**第三**，Sentinel 限流熔断；**第四**，Seata 分布式事务保证订单和库存一致。你看压测结果——100 个请求，约 10 个成功下单，其余被限流保护，无超卖。

### 截图重点
- Sentinel Dashboard QPS 曲线（尖峰被削平到 10）
- SkyWalking 秒杀服务 QPS 从 0→峰值
- 压测脚本输出（成功/限流统计）

## 第二段：AI 智能导购（1:45–3:15）🔴 重点

**目标**: 展示 RAG 流水线 + 流式输出 + 语义理解（差异化亮点）

### 操作步骤
1. 首页点击"AI 智能导购"（需登录）
2. 输入"学生党高性价比手机推荐"
3. 展示思考过程可视化卡片（意图识别→召回→排序）
4. 展示 SSE 流式输出逐字渲染
5. 展示返回的商品卡片

### 讲解话术
> **AI 导购是这个项目的差异化亮点**。我接入了 DeepSeek 大模型，构建了一条完整的 RAG 流水线：用户输入自然语言 → AI 意图识别 → 查询扩展 → ES 多路召回 → 向量检索 → 重排序 → SSE 流式输出。
>
> 你看这里，输入"学生党高性价比手机"，AI 不是简单关键词匹配，而是**理解语义**——它识别出用户在意"性价比"，然后从商品库里筛选出高性价比机型，逐字流式展示思考过程。前端还有可视化卡片，展示 AI 的每一步处理。这背后是 BGE-M3 向量模型做语义检索，和传统搜索完全不同。
