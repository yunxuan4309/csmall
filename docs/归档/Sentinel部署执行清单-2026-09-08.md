## 一、背景（审计实证）

| 事实 | 证据 |
|---|---|
| 秒杀限流当前**实际失效** | seckill 日志：代码规则 QPS=10 加载后，Nacos datasource 空配置 → `converter can not convert rules because source is empty` → **空规则覆盖本地** |
| Nacos 规则全空 | SENTINEL_GROUP / DEFAULT_GROUP 下 mall-seckill-flow-rules 等 dataId 均不存在 |
| order/sso 注解空转 | 有 @SentinelResource 无 datasource → 无规则可加载 |
| degrade 空转 | seckill prod 配了 degrade datasource，Nacos 无 degrade 规则 |

**机制**（覆盖坑）：配了 Nacos datasource 后 FlowRuleManager 权威源 = Nacos（整体替换非叠加）；Nacos 空配置会**擦除**本地代码规则。

## 二、Nacos 建规则（5 个 dataId，group=SENTINEL_GROUP，JSON 见 `deploy/docker/sentinel/`）

```bash
# 以 mall-seckill-flow-rules 为例；逐个 dataId 发布（内容=对应 json 文件）
curl -X POST "http://localhost:8848/nacos/v1/cs/configs" \
  -d "dataId=mall-seckill-flow-rules&group=SENTINEL_GROUP&type=json&content=$(cat deploy/docker/sentinel/mall-seckill-flow-rules.json)"
```

| dataId | 内容 |
|---|---|
| `mall-seckill-flow-rules` | 秒杀订单提交 QPS=10 |
| `mall-seckill-degrade-rules` | 秒杀订单提交 慢调用(RT>2s 比例 0.5 → 熔断 10s) |
| `mall-order-flow-rules` | 新增订单 QPS=20、支付订单 QPS=20 |
| `mall-order-degrade-rules` | 新增订单/支付订单 慢调用熔断 |
| `mall-sso-flow-rules` | adminLogin QPS=10 |
| `mall-sso-degrade-rules` | ❌ 不建（adminLogin 无 degrade 场景，登录失败是业务异常非故障） |

> ⚠️ 建规则顺序坑：**先建 Nacos 规则 → 再重启 order/sso/seckill 容器**。
> 若先重启：order/sso datasource 拉空 → 空转无害；seckill 会复现"空覆盖"。
> 建完后验证：`curl "http://localhost:8848/nacos/v1/cs/configs?dataId=mall-seckill-flow-rules&group=SENTINEL_GROUP"` 返回 JSON。
