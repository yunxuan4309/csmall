## 启动顺序

```
1. 中间件：MySQL → Redis → Nacos → RabbitMQ → ES → Seata
2. 可观测性：SkyWalking (startup.bat) → Sentinel Dashboard (IDEA 8090)
3. 独立服务：mall-resource → mall-ams → mall-ums
4. Dubbo 提供者：mall-product
5. Dubbo 消费者：mall-front → mall-order → mall-search → mall-ai
6. 秒杀：mall-seckill
7. 网关入口：mall-sso → mall-gateway-server
```
